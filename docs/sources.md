# Анализ источников итогов торгов

Дата анализа: 2026-10-23.  
Портал **никогда** не обращается к сайтам бирж — только парсеры.

---

## 1. ETS (Товарная биржа ETS)

**URL:** https://ets.kz/documents/trading-results/  
**Технологии:** Bitrix CMS, серверный HTML, без SPA.  
**Формат данных:** ежедневные файлы **XLSX** (не PDF, не JSON API).

### Структура каталога

```
/documents/trading-results/
  ├── 2025-god/                          # год
  │     └── itogi-torgov-2025-god-{месяц}/
  │           └── ссылки на .xlsx (по датам торгов)
  └── itogi-torgov-2026/
        └── itogi-torgov-2026-god-{месяц}/
              └── DD.MM.YYYY … ИТОГИ ТОРГОВ → /upload/iblock/.../*.xlsx
```

- На корневой странице — список годовых разделов.
- Внутри года — месячные разделы.
- Внутри месяца — список документов с датой в названии и ссылкой XLSX на `/upload/iblock/...`.

### Поля в XLSX (лист с датой в имени, например `07.10`)

| Колонка в файле | Поле MVP | Есть? | Комментарий |
|---|---|---|---|
| Дата в заголовке / имени файла | Дата торгов | Да | Время **нет** |
| — | Биржа | Да | Всегда `ETS` |
| Наименование товара | Наименование | Да | Часто двуязычно (KZ/RU), базис поставки вшит в название |
| Код ТН ВЭД ЕАЭС | ТНВЭД | Да | |
| Код товара | Код товара | Да | Биржевой тикер (например `W4DE700`, `D3DE1EA`) |
| Наименование продавца + БИН | Продавец | Да | |
| Наименование покупателя + БИН | Покупатель | Да | |
| Брокер продавца / покупателя | Брокеры | Да | Только наименование, БИН брокера нет |
| Объём + единица | Объём | **Нет** | Вычисляем: `сумма / средневзвешенная_цена`; единица обычно «т» (неявно) |
| Цены: открытие/закрытие/макс/мин/средневзвешенная | Цена за ед. | Частично | В MVP берём **средневзвешенную**; НДС **не указан** |
| Общая сумма сделки | Сумма | Да | В тенге |
| — | Место поставки | Частично | Извлекаем из наименования (EXW/FCA/CPT + локация) |
| — | Срок поставки | **Нет** | NULL |
| Количество заключённых сделок | служебное | Да | Строка может агрегировать несколько сделок |

Строка «Итого» в конце листа — **не сделка**, пропускается.

### Способ парсинга

1. Обход HTML каталога (requests + BeautifulSoup/lxml).  
2. Скачивание XLSX, разбор openpyxl.  
3. Playwright/Selenium **не нужны**.

### Robots / вежливость

- `https://ets.kz/robots.txt` фактически отдаёт HTML страницы (отдельного запрета на `/documents/` не выявлено).  
- Паузы между запросами, стабильный User-Agent, повторные попытки при сетевых ошибках.

## 2. Каспий (CCX — Caspian Commodity Exchange)

**URL:** https://ccx.kz/trading-and-analytics/trading-results  
**Технологии:** Laravel + фронтенд-сборка (Vite), **серверный HTML**-таблица (не чистый SPA).  
**Формат данных:** HTML-таблица на странице; отдельного публичного JSON/XLS API для итогов **не найдено**.

### Доступ к данным

- Русский интерфейс: `?lang=ru`.
- Пагинация: `?page=N&per_page=M` (проверено: `per_page=20/50/100`).
- Фильтры на сайте: `date_from`, `date_to`, `product_code`, `section_code`, `tn_ved`, имена брокеров/участников, `delivery_term`, `search` — через GET-параметры формы.
- Для исторической загрузки парсер листает страницы с `lang=ru` и при необходимости фильтром по датам.
- Playwright **не требуется**: разметка таблицы есть в ответе HTTP без исполнения JS.

### Колонки таблицы (lang=ru)

| Колонка на сайте | Поле MVP | Есть? | Комментарий |
|---|---|---|---|
| Дата | Дата торгов | Да | Время **нет** |
| — | Биржа | Да | Всегда `Каспий` |
| Наименование товара | Наименование | Да | |
| Код ТН ВЭД ЕАЭС | ТНВЭД | Да | Иногда `-` |
| Код товара | Код товара | **Нет** | NULL (на UI есть фильтр `product_code`, в таблице колонки нет) |
| Наименование продавца | Продавец + БИН | Частично | БИН часто **в конце строки имени** (парсим regex); обрезание `…` возможно |
| Наименование покупателя | Покупатель + БИН | Частично | Аналогично |
| Брокер продавца / покупателя | Брокеры | Да | Без БИН |
| Объём + единица | Объём | **Нет** | Вычисляем `сумма / средневзвешенная_цена`; единица NULL/`т` |
| Цены (откр/закр/макс/мин/средневзв.) | Цена | Частично | Берём средневзвешенную; НДС **не указан** |
| Сумма сделки | Сумма | Да | Тенге; пробелы как разделители тысяч |
| Условие поставки | Место/базис | Частично | Базис (FCA, CPT, …); полный адрес часто отсутствует |
| — | Срок поставки | **Нет** | NULL |
| Общий оборот по сделкам за день | служебное | Да | Строки «ИТОГО по дате» — **не сделки** |
| Кол-во заключённых сделок | служебное | Да | |

### Robots / вежливость

- `https://ccx.kz/robots.txt`: `User-agent: *` / `Disallow:` (пусто) — обход не запрещён.  
- Паузы, User-Agent, обработка 5xx/таймаутов.  
- **Важно:** с части зарубежных IP доступ к `ccx.kz` может блокироваться Единым шлюзом РК; парсер рассчитан на запуск из доступной сети (локально в РК / VPN).

## 4. Выбор инструментов (зафиксировано)

| Источник | Инструмент | Почему |
|---|---|---|
| ETS | `requests` + BeautifulSoup + `openpyxl` | Каталог HTML + файлы XLSX |
| Каспий | `requests` + BeautifulSoup | Серверный HTML, пагинация query-string |
| Playwright/Selenium | не используются в MVP | JS не обязателен для извлечения строк |

Нормализация: даты → ISO `YYYY-MM-DD`, числа (пробелы/`nbsp`/запятые) → `Decimal`, названия — `strip` + сжатие пробелов, регистр сохраняем как в источнике (без агрессивного UPPER).
